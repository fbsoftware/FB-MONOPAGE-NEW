# FB-MONOPAGE
FB-EDITOR

Editor visuale di pagine web basato su JavaScript, PHP e JSON.
FB-EDITOR è un progetto di editor web che consente di costruire e modificare pagine attraverso un'interfaccia visuale, organizzando i contenuti in sezioni, colonne e widget.
L'obiettivo è offrire un ambiente di editing pratico e flessibile, mantenendo separati la struttura dei contenuti, la loro configurazione e il rendering del sito pubblico.
Funzionalità principali
•	Editor visuale: gestione di sezioni, colonne e widget con Inspector delle proprietà.
•	Widget configurabili: testi con editor rich text, titoli, immagini, gallerie, slider, icone, divisori, separatori e spaziatori.
•	Tipografia globale: famiglie di caratteri, pesi e dimensioni configurabili.
•	Palette globale: colori primario, secondario, accent, testo e sfondo.
•	Material Symbols: selettore visuale delle icone con ricerca e anteprima.
•	Libreria Media: gestione delle immagini organizzate in cartelle, con caricamento, sostituzione e cestino.
•	CSS personalizzato: possibilità di personalizzare ulteriormente gli elementi.
•	Persistenza JSON: salvataggio delle configurazioni delle pagine.
•	Rendering PHP: generazione delle pagine pubbliche a partire dai dati dell'editor.
Tecnologie
•	JavaScript e jQuery
•	PHP
•	HTML5 e CSS3
•	JSON
•	TinyMCE
•	Google Material Symbols
Struttura del progetto
Tra i principali componenti:
•	editor-core.js — logica centrale dell'editor
•	editor-sections.js — gestione delle sezioni
•	editor-columns.js — gestione delle colonne
•	editor-widgets.js — definizione e rendering dei widget nell'editor
•	site-renderer.php — rendering delle pagine pubbliche
•	save.php — salvataggio dei contenuti
Ambiente di sviluppo
Il progetto viene sviluppato e testato in ambiente Windows con Apache e PHP tramite XAMPP.
Le istruzioni complete di installazione e configurazione saranno documentate prima della distribuzione pubblica.
Stato del progetto
FB-EDITOR è in sviluppo attivo. Le principali funzionalità di editing e pubblicazione sono operative; proseguono i miglioramenti dell'interfaccia, dei widget e della configurazione grafica.
